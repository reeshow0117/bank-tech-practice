# 银行科技岗 · 通用刷题题库

一个单文件、可离线打开的刷题网站，面向银行科技 / 研发 / 数据类岗位笔试练习。

## 内容

- 424 道原创模拟题：职业能力 100、英语 72、计算机基础 140、编程思维 72、银行业务场景 40
- 每题附答案与解析，可在作答前直接查看
- 收藏、错题本、搜索、分科筛选、跳到未做题
- 四模块限时练习卷（44 题 / 60 分钟，各模块独立计时）

## 使用

直接用浏览器打开 `index.html` 即可，无需联网、无需安装。答题记录、收藏和成绩只保存在当前浏览器的本地存储里，清除浏览器数据会丢失。

## 说明

题目依据公开招聘信息与往届考生笔经中的考点方向原创编写，**不是任何银行的官方真题**。练习卷的题量和时长由本站自定，不对应任何银行的正式考试；实际科目与安排以目标银行的招聘通知为准。
